# Modus Vivendi (Yazi flavor)

Dark half of the [Modus themes](https://protesilaos.com/emacs/modus-themes) by
Protesilaos Stavrou — highly accessible, WCAG AAA contrast. Accent is Modus's
canonical blue (`#2fafff`).

Locally authored for this dotfiles setup: UI colors mapped from the canonical
Modus Vivendi palette (also published via
[miikanissi/modus-themes.nvim](https://github.com/miikanissi/modus-themes.nvim)
`extras/`). Preview syntax (`tmtheme.xml`) omits italics to match the editor config.

Paired with `modus-operandi.yazi` (light) via `theme.toml`'s `[flavor]` dark/light keys.
